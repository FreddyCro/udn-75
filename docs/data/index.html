深入體驗聯合報數位版

每天打開新聞媒體，有人想看股市、有人想掌握國際局勢，也有人關心教育大小事。

過去，閱聽眾需要花時間搜尋、篩選，才能找到自己真正需要的新聞資訊。如今，「聯合報數位版」透過「AI推薦」新聞的技術，從訂戶過去在網站中的閱讀足跡與興趣出發，主動整理訂戶需要知道或感興趣的新聞。

對訂戶有意義的新聞，在他搜尋之前就已備妥，讓資訊獲取更有效率，也更貼近訂戶的新聞需求。

若想進一步瞭解新聞時事走向，「AI搜尋」則成為隨時待命的新聞助理。不必翻找、回溯大量新聞資料，只要提出問題，「聯合報數位版」AI搜尋系統便能快速將新聞事件串聯成脈絡，並表列相關報導，協助讀者掌握事件全貌及最新進度。

但AI不只是精準的演算法，更在於對閱聽眾的理解。訂戶在「聯合報數位版」系統中的每一次搜尋、「聯合報數位版」每一次的新聞推薦，都希望幫助訂戶在資訊洪流中，更有效率找到真正需要的新聞。

在AI快速改變世界的時代，「聯合報數位版」持續追求產品服務的細心與貼心，不只要快速回應使用者的新聞需求，更希望成為「智慧心媒體」，讓「每一次的新聞閱讀」成就「每一次的深刻思考」，促使「每一次的社會改變」。
