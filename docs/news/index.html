論壇永續祝福智慧新媒體

AI時代的媒體，如何既保有第四權獨立性，又實現內容價值極大化？
新時代新聞人，除了敏銳新聞鼻，數據分析已成為導航儀。「數據驅動」議題開發及內容設計的觀念及作法，不能光說不練，它需要工具。其核心關鍵，就在於「結構化」；合適的工具，結構化內容產品，也結構化經驗智慧。

新聞部的數位轉型在2016年起了重大變化！時任總編輯游美月籌組「數位編輯台」的任務小組，以數位優先為前提，全力衝刺即時新聞；加上「新聞郵差」策略奏效（記者主動推薦轉傳給閱讀需求的生態圈），一年流量翻轉四倍。

衝流量到拚訂閱　
數位化十年深耕

2017～2019年，聯合報粉絲團先整併19個地方粉團，成為報系互動最緊密的百萬粉絲團，也陸續開發AR互動濾鏡、求籤機器人與政見投票等技術型小遊戲；緊接著開啟9.8萬的商業模式，協助業務單位爭取商業短影片，開創社群的多元營收的商業合作至今。

2020～2022年，時任內容長的蕭衡倩支持採訪中心增購30組手機腳架，啟動第一線同仁粉絲團的手機直播；超過七成的同仁擁有直播採訪的能力，衝出強大流量，成為全國覆蓋率最大、最快速的直播團隊。

同時期，新聞部啟動全媒體平台發動，從新聞網即時滾動、粉團社群擴散、數位版內容加值、報版收斂精緻化，讓突發新聞、火熱議題，優先從數位的快速提供，有效率的轉移到各平台上，發揮領先其他競媒的數位影響力。

面對媒體大環境質變，充斥農場文或重複性高的內容，新聞部在內容長蕭衡倩領軍下，2020年11月1日聯合報正式推出訂閱制《聯合報數位版》，先讀懂用戶的心，再向用戶收費。新聞部搭配數據發展部合組開發團隊，發展「智慧內容 Curate X」，依不同主題共識地圖對新聞內容進⾏分類，評估受眾興趣。

全球媒體產業都在嘗試理解受眾，但除了數據資料、儀表板，還需要可以解決編務流程痛點的相對應工具，「智慧內容 Curate X」等工具就是在看清全球趨勢下誕生。

智慧策展流程、智慧檢索系統的運作邏輯是協助內容開發、內容設計和數據培訓。其目的是識別垂直新聞平台上的⽤⼾行為，使⽤共識地圖進⾏分類與頻道架構，依據儀表板查詢過去策展主題類別及⼦類別的績效表現，並依⽤⼾關注程度較⾼的內容，訂定開發和運營優先順序。

團團隊中的數據發展部同仁依照編務需求，開發「UDN智慧策展aiAssist」，更有效提升《聯合報數位版》訂單轉換率，最高曾以四分之一的稿量，轉換全站近半的訂單。聯合報訂閱制也從 2022年到2025年，連續在世界媒體組織評選中，獲得最佳訂閱制金獎等獎項。

AI革命全面進化　
打造媒體新典範

團隊固定在雙周主題例會解讀智慧洞察分析，持續優化內容設計、標題/牆前摘要、實驗設計，並設計符合受眾需求的內容上架策略。運⽤範圍也擴到影音及音頻內容，識別⽤⼾對節⽬規劃的興趣，以數據驅動協作內容、品牌開發，識別特定內容和品牌中的⽤⼾⾏為特徵，並實施分眾策略。

2025年，當AI衝擊全球媒體生態，新聞部研發出一套AI輔助決策系統「Publish X 議題智囊包」，它匯集多位新聞部資深主管卅多年的專業經驗，建置8大發動流程與41個採訪情境，涵蓋政治、財經、司法、國際、生活、社會、醫藥、重大突發等8大新聞模組的結構化知識庫。

它將聯合報系的機構智慧透過RAG對接數據基礎，以大型語言模型輸出最佳化的過程，預判閱讀需求，協助新聞部決策者在報網合一架構下，最快可在70秒內協助歸納出資深副總們的經驗智慧，並產出整合版、平台版（即時、 付費內容、 社群、影音及報版）兩種分析稿單，最終由新聞室最高階主管依當下情勢判斷選用。

最大的亮點是使用超簡單！只要在LINE上對話框輸入「類別：、標題：、內容：」，它立即就會產生簡易版一主五配的角度規劃及資訊圖表的建議，附帶連結內有完整的「報版、即時、數位版、社群、影音」等多模態，適用全媒體發動的推薦，還提供競媒的第一波數位比報，快速協助決策者預判、洞悉讀者需求，更有效率執行議題滾動。

新聞部由內容長范凌嘉、總編輯王茂臻領軍，從上而下執行「Publish X 議題智囊包」落地應用，追蹤一年的流量成效，增益倍數最高達4.5倍。這項創新的AI工具，同時在2026年世界新聞出版協會（WAN-IFRA）、國際新聞媒體協會（INMA）所辦的兩大媒體數位大賽上，大放異彩，更一舉拿下WAN-IFRA「最佳創新數位產品」全球金獎！

開發「Publish X 議題智囊包」初衷是：「創造媒體存在價值、留存媒體未來價值」；未來新聞部將持續以新聞專業知識與數據洞察為核心，創造更多AI應用與新聞工作深度融合的系統工具，實現效率與品質並重，成為數位再轉型，媒體永續經營的全球典範。
